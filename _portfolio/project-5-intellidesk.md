## Overview

**IntelliDesk** is a web-based helpdesk application designed to organize incoming requests and assist with drafting support responses.

## Key Features

* **Automated Ticket Classification**: Classifies incoming customer requests into high-urgency, billing, technical, or general feedback tiers using fine-tuned language models.
* **Smart Draft Synthesis**: Synthesizes contextual response suggestions drawing upon past resolutions and company knowledge bases for agent one-click approval.
* **Modern Web Interface**: Clean, accessible responsive frontend constructed with React, delivering seamless agent onboarding, queue triage, and analytics.
