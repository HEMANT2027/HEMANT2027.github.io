## Overview

The **Electric Grid Simulation Platform** is a real-time smart grid visualization and simulation framework designed to model India's high-voltage electrical transmission topology. It solves critical challenges in grid stability analysis, sensor instrumentation optimization, and contingency simulation.

## Key Features

* **Graph-Based Topological Modeling**: Engineered an end-to-end Python data pipeline leveraging `NetworkX` to parse, validate, and compute power flows across substations, transformers, and high-voltage transmission lines.
* **Interactive Geo-Spatial Dashboard**: Designed a responsive web interface using **React** and **Leaflet** maps, allowing engineers to visualize nationwide substations, grid nodes, and interconnections dynamically.
* **Dynamic Grid Energization & Fault Injection**: Simulates line trips, transformer overloads, and islanding events in real time to study cascading failure dynamics.
* **Optimal Sensor Placement**: Formulated graph-theoretic optimization routines to identify minimal sensor sets that ensure maximum grid observability and prompt fault detection.
